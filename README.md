# Puppy Finder

RuneLite plugin for locating the optional puppy breeds unlocked after **A Ruff Situation**.

The plugin:
- highlights any unfound puppy currently loaded in the scene;
- uses the native OSRS flashing yellow hint arrow on a loaded unfound puppy;
- shows an on-screen location panel for the remaining puppies;
- lets you manually mark each puppy as found in the plugin configuration.

Checking a puppy in the **Found puppies** section removes its location from the panel and prevents that puppy from being highlighted or targeted by the hint arrow. The **Show info box** setting controls whether the location panel is visible.
